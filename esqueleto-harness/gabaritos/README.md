# Gabaritos

Exemplos aprovados pela empresa, usados para testar as skills antes de liberar e depois de cada melhoria.

Para cada skill, guarde de 3 a 5 pares:
- `<skill>/<nome>/entrada/`: o material original (áudio transcrito, anotações, arquivos)
- `<skill>/<nome>/esperado.md`: a saída que a empresa aprovou

Como usar: rode a skill sobre a entrada e compare com o esperado. Registre o resultado com `registrar-decisao` (tipo `execucao`, projeto `INTERNO`). Só suba uma skill de nível B para A com o histórico mostrando acerto consistente.

Retire dados pessoais e nomes de clientes dos gabaritos.
