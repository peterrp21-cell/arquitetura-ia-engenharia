# Normas e procedimentos

Coloque aqui:
- procedimentos internos, manuais, checklists e padrões da empresa;
- normas técnicas **somente se a empresa tiver licença** que permita esse uso.

A skill `consulta-procedimentos` responde perguntas com base nestes arquivos e sempre cita o arquivo e a seção. Se a resposta não estiver aqui, ela diz que não encontrou, em vez de responder de memória.
