# Nomenclatura

Sem nome padrão a IA erra a triagem e ninguém acha nada. Preencha e siga.

## Código de projeto ou obra
- Projeto: `P-AAAA-NNN` (ex.: `P-2026-014`)
- Obra: `O-AAAA-NNN`
- Interno: `INTERNO`

## Disciplinas (use sempre a sigla)
| Sigla | Disciplina |
|---|---|
| ARQ | Arquitetura |
| EST | Estrutura |
| HID | Hidrossanitário |
| ELE | Elétrico |
| PCI | Prevenção e combate a incêndio |
| CLI | Climatização |
| [ ] | [ ] |

## Arquivos
`<código>_<disciplina>_<tipo>_<rev>.<ext>` → ex.: `P-2026-014_HID_MEMORIAL_R02.docx`

## Fases
EP (estudo preliminar) · AP (anteprojeto) · PE (projeto executivo) · AO (apoio à obra)
