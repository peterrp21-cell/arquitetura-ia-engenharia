# 01. Autodiagnóstico

Responda cada pergunta com a nota que mais se aproxima da realidade da sua empresa hoje, não da que você gostaria de ter.

**0** = não existe · **1** = existe, mas depende de pessoa ou é informal · **2** = existe, é padronizado e todo mundo usa

## Dados

| # | Pergunta | Nota |
|---|---|---|
| D1 | Cada obra ou projeto tem um código único usado em todos os sistemas e planilhas? | |
| D2 | Existe um lugar oficial para cada informação (projeto, orçamento, cronograma, contratos) e todo mundo sabe qual é? | |
| D3 | Os nomes de disciplinas, serviços e etapas seguem um padrão da empresa? | |
| D4 | O que acontece na obra ou no projeto (RDO, apontamento, medição) fica registrado de forma estruturada, não só em texto livre ou WhatsApp? | |
| D5 | Dá para saber quem alterou uma informação e quando? | |

## IA

| # | Pergunta | Nota |
|---|---|---|
| I1 | A empresa tem uma ferramenta de IA aprovada para uso, em vez de cada um usar a sua? | |
| I2 | Existem prompts ou modelos de uso compartilhados para as tarefas que mais se repetem? | |
| I3 | A IA consegue acessar dados reais da empresa sem que alguém copie e cole? | |
| I4 | Existe pelo menos um uso de IA com ganho medido (horas, retrabalho, prazo)? | |
| I5 | Quem usa IA sabe o que ela faz mal e onde precisa conferir? | |

## Governança

| # | Pergunta | Nota |
|---|---|---|
| G1 | Está definido o que a IA pode fazer sozinha e o que precisa de aprovação humana? | |
| G2 | Existe regra sobre quais dados podem ou não ser enviados para ferramentas de IA? | |
| G3 | Toda informação gerada por IA que vai para cliente, contrato ou assinatura passa por revisão de um responsável? | |
| G4 | Alguém é dono do tema IA na empresa, com tempo para isso? | |
| G5 | Os resultados dos usos de IA são revisados de tempos em tempos? | |

## Resultado

Some as notas de cada camada (máximo 10 por camada, 30 no total).

| Total | Nível | O que significa |
|---|---|---|
| 0 a 8 | **1. IA avulsa** | Cada um usa do seu jeito. O ganho existe, mas é individual e invisível. |
| 9 a 16 | **2. IA com método** | Há padrões de uso, mas a IA ainda trabalha longe dos dados. |
| 17 a 24 | **3. IA conectada** | A IA acessa dados reais e alguns ganhos já são medidos. |
| 25 a 30 | **4. IA na operação** | Dados, IA e governança funcionam juntos e evoluem. |

**Mais importante que o total:** a camada com a menor nota é o seu gargalo. Comece por ela.
